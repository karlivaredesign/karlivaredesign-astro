# Next Century Spirits — gallery assets

Drop files in this folder using these names (match `src/content/projects/next-century-spirits.mdx`):

| # | Layout | Files |
|---|--------|--------|
| 1 | Full width (video) | `gallery-01.mov` |
| 2 | Full width (image, 1360×630) | `gallery-02.jpg` |
| 3 | Half width portrait (video · video, 644×822) | `gallery-03-left.mov`, `gallery-03-right.mov` |
| 4 | 2/3 landscape · 1/3 portrait (image · video) | `gallery-04-landscape.jpg`, `gallery-04-portrait.mov` |
| 5 | Full width (video) | `gallery-05.mov` |
| 6 | 2/3 landscape · 1/3 portrait (video · image) | `gallery-06-landscape.mov`, `gallery-06-portrait.jpg` |
| 7 | Two col square (image · image) | `gallery-07-left.jpg`, `gallery-07-right.jpg` |

`.mp4` / `.webm` / `.png` work in place of the extensions above if you update paths in the MDX.

Optional video posters: add `poster` on any `type="video"` frame in the MDX.
