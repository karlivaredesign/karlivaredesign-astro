# Draig Therapeutics — gallery assets

Drop files in this folder using these names (match `src/content/projects/draig-therapeutics.mdx`):

| # | Layout | Files |
|---|--------|--------|
| 1 | Full width (video) | `gallery-01.mov` |
| 2 | 3 col portrait (video · image · video) | `gallery-02-left.mov`, `gallery-02-center.jpg`, `gallery-02-right.mov` |
| 3 | Full width (video) | `gallery-03.mov` |
| 4 | 2/3 landscape · 1/3 portrait (image · image) | `gallery-04-landscape.jpg`, `gallery-04-portrait.jpg` |
| 5 | Full width (video) | `gallery-05.mov` |
| 6 | Half width landscape (image · image) | `gallery-06-left.jpg`, `gallery-06-right.jpg` |
| 7 | Full width (video) | `gallery-07.mov` |
| 8 | 2/3 landscape · 1/3 portrait (video · image) | `gallery-08-landscape.mov`, `gallery-08-portrait.jpg` |

`.mp4` / `.webm` work in place of `.mov` if you update paths in the MDX file.

Optional video posters: add `poster` on any `type="video"` frame in the MDX.
